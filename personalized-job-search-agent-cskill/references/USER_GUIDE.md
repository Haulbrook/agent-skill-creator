# User Guide - Personalized Job Search Agent

## Getting Started

### 1. Create Your Profile

First, tell the agent about yourself:

```
"Create my job search profile. I'm a [role] with [X] years of experience in
[skills]. I'm looking for [desired roles] paying [salary range] at [company types]
in [locations]."
```

Example:
```
"Create my job search profile. I'm a senior software engineer with 8 years of
experience in Python, JavaScript, and AWS. I'm looking for remote staff engineer
roles paying $150k-$200k at fintech or healthtech startups."
```

### 2. Search for Jobs

```
"Find me jobs that match my profile"
"Search for [job title] in [location]"
"What are the best jobs for my skills?"
```

### 3. Analyze Opportunities

```
"Analyze the first job in detail"
"Compare the top 3 matches"
"Show me the pros and cons of this position"
```

### 4. Apply

```
"Apply for this job"
"Generate a cover letter for this position"
"Submit applications to all jobs with 90%+ match"
```

### 5. Track Applications

```
"Show my application status"
"Any updates on my applications?"
"What jobs have I applied to this week?"
```

## Understanding Match Scores

- **90-100**: Excellent Match ⭐⭐⭐⭐⭐ - Apply immediately
- **75-89**: Great Match ⭐⭐⭐⭐ - Strongly consider
- **60-74**: Good Match ⭐⭐⭐ - Review carefully
- **45-59**: Decent Match ⭐⭐ - Consider if interested
- **Below 45**: Poor Match ⭐ - Look for better options

## Tips for Better Results

1. **Be Specific**: More details in your profile = better matches
2. **Update Regularly**: Keep skills and preferences current
3. **Review Recommendations**: The agent learns from your feedback
4. **Set Realistic Expectations**: Balance requirements with market reality
5. **Track Everything**: Use application tracking to stay organized
